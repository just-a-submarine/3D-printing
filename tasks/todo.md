# ROV Hull v5.1 修訂（2026-07-19，同日第三輪）

## 需求（使用者指定）

1. 螺絲/螺帽要有**真實螺紋**才能旋緊（v5.0 的螺紋被 fuse 悄悄弄丟）
2. 底部平臺**留部分空心**省塑膠（不要全實心）
3. 平臺前段挖**配重塊凹槽**（配重塊 65.6 × 42.2 mm；後段已有電池艙）

## 設計決策

- **螺紋根因**：`core.fuse(thread)` 產生 Solids=2（OCC 未合併，螺旋面相接處退化），
  之後 common 把螺紋丟掉 → v5.0 螺絲體積 365 = 純圓柱值。
  **修法：fuzzy fuse `core.fuse(thread, 0.05)`** → Solids=1、vol=182.7 實測通過
- 螺紋規格 v5.1：芯 D3.0（1.5）、牙深 0.7、牙頂 D4.4（2.2，可過 D4.8 孔）、pitch 2；
  螺帽刀具芯 r1.75、同牙深 0.7（+0.25 徑向間隙）、長 6.5 平移 −1.25
- 平臺空心腔 ×2（封閉腔、45° 斜頂可列印，直立列印時腔為垂直牆+斜頂）：
  截面 Y=−55~−48 ∩ R57 圓柱（距內壁 1.5）∩ X±32；
  後腔 Z=12~100（93 起 45° 收斜）、前腔 Z=150~230（223 起收斜）；
  中段 Z=100~150 保留實心（垂直馬達殼 R18 @Z=125 ± 保護 7mm）
  頂板：一般區 8mm、電池艙/配重凹槽下 3mm；腔底距內壁 ≥3.5mm
- 配重凹槽：67.6(Z) × 44.2(X) × 深 5（底 Y=−45），Z=160~227.6（+2mm 間隙同電池艙慣例）
- 端蓋不動；ROV_Hull.stl / ROV_Fasteners.stl 重匯出，ROV_EndCaps.stl 不變

## Review

- **HULL**：Vol 551,962 → **482,823 mm³**（省 88g；殼體 ≈613g）、BB 202×172×250、
  Solids=1、isValid、isClosed 全過；空腔/頂板/凹槽/配重塊放入/電池艙/馬達孔/引線孔/墊圈凹槽
  12 探針全 PASS
- **螺絲**：Vol=371.8（無牙基準 335.3，螺紋 +36.5 ✓）；**螺帽**：233.7（理論 233.6 ✓），
  內牙扇形探針 0.55/0.72=76%（理論 ~75% ✓）；過 D4.8 孔 0；旋合干涉 cut 法 0 / fuse 和法 0.012
- **根因**：v5.0 螺紋遺失 = `fuse` 對 helix 掃掠體回傳 Solids=2 → common 丟棄；
  另發現 `common` 對環形刀具×螺旋面靜默回傳 0（v5.0 的旋合探針是假陰性）→ 教訓 #8
- **浮力**：淨浮力 ≈ +790g；配重塊放前段凹槽（65.6×42.2），與後段電池配平衡
- 列印注意：螺絲直立列印 0.12~0.16 層高；螺紋牙深 0.7 屬 FDM 極限附近，首印試旋合，
  過緊反覆旋合磨合、斷裂改金屬 M4×20
