## 2026-04-06　馬達修正 + 清理多餘特徵（第二次重建）

### 背景

使用者指出以下問題並要求修正：

1. **馬達孔軸向錯誤**：原版用 `V(-1,0,0)`（X 方向）鑽孔 → 馬達軸線沿 X = 側向推力，完全錯誤
2. **底部兩條突出物**：電池擋塊座標落在外壁外側（V(27.5, -40.5, 12) 距原點≈48.95mm > R_out=45mm），造成外壁出現突出條塊
3. **莫名方塊**：MS5837 黏貼座（15×15×3mm）插在船底外壁，外觀不合理
4. **垂直馬達 Z 位置**：模型用 Z=30，使用者要求改為 **Z=100**（與水平馬達同截面）

### 決策

- 馬達孔方向改為 Z 軸（`V(0,0,1)`），開口在臂的後端面 Z=75，深度 30mm，螺旋槳朝後（-Z 方向）
- 孔圓心：X=R_out+arm_x_len-16=62，Y=arm_y_offset+arm_y_len/2=15（臂中心）
- 電池擋塊：刪除（改用 EVA 泡棉防晃，無需模型特徵）
- MS5837 座：刪除（環氧樹脂直接黏貼光滑外壁即可）
- 垂直馬達：Z=30 → Z=100

### 執行內容

CSG 重建，改動項目：

```python
# 垂直馬達（Z=100，沿 -Y 方向）
hull.fuse(Part.makeCylinder(19, 78, V(0,0,100), V(0,-1,0)))
hull.cut(Part.makeCylinder(16, 30, V(0,-78,100), V(0,1,0)))   # 馬達嵌入孔

# 水平馬達孔（Z 方向，從後端面 Z=75 朝 Z+ 鑽入）
hull.cut(Part.makeCylinder(16, 30, V(62, 15, 75), V(0,0,1)))  # 右舷
hull.cut(Part.makeCylinder(16, 30, V(-62, 15, 75), V(0,0,1))) # 左舷（鏡像）
```

- 截圖 7 個方向：Isometric、Front、Rear、Right、Left、Top、Bottom
- 匯出 `ROV_Hull_v2.stl`（覆蓋）

### 結果

BoundBox：X=156mm、Y=131mm、Z=200mm。
馬達孔開口正確朝後（Z=0 方向），垂直馬達與水平馬達同 Z=100 截面。

## 2026-04-07　乾淨重建（修正觀察窗球殼布林 + 尾翼翼根延伸）

### 背景

使用者反映觀察窗仍有問題：球殼未貼合外殼弧面、Plug+Cut 產生大量布林痕跡、法蘭唇未移除。
上一次對觀察窗 D=28→30mm 的修改使用 Plug+Cut 方法，Faces 從 56 暴增至 90、Edges 從 128 暴增至 235，品質嚴重退化。

### 根因分析

經分析找出三個核心問題：

1. **球殼裁切方式錯誤**：舊腳本用 `makeBox` 平面裁切球殼底部，但外殼是圓柱面 → 球殼底部為平切面，與弧形外壁之間有間隙，無法形成實體重疊
2. **布林順序錯誤**：舊腳本先 cut 觀察窗孔，再 fuse 球殼 → 球殼只能與孔洞邊緣接觸（無體積重疊），FreeCAD 的 `fuse()` 無法合併 → 產生孤立 Solid
3. **尾翼翼根僅邊緣接觸**：舊腳本尾翼起點在 X=R_out（外壁表面），與外壁只有面接觸 → `fuse()` 無法合併 → 又產生孤立 Solid

### 修正方案（三項關鍵修改）

| 問題 | 舊做法 | 新做法 |
|------|--------|--------|
| 球殼裁切 | `makeBox` 平面裁切 | `makeCylinder(R_in)` 圓柱裁切 → 球殼底部貼合弧面，與壁厚重疊 1.5mm |
| 布林順序 | 先 cut 孔 → 再 fuse 球殼 | **先 fuse 球殼**（壁完整 → 實體重疊）→ **再 cut 孔** |
| 尾翼翼根 | 起點 X=R_out（邊緣接觸） | 起點 **X=R_out-2**（穿入壁內 2mm）+ fuse 後 `cut(R_in)` 修整艙內 |

從 §13 參考腳本出發，套用上述三項修正，完整重建所有 9 個特徵：

1. 主體圓筒（OD=90, wall=1.5, L=200）

## 2026-04-07　消除觀察窗球殼 Z=140 平板面（球體削切法）

### 背景

使用者在截圖中發現觀察窗圓頂區域出現一塊「莫名其妙的板子」——一個平坦的環狀面位於 Z=140 附近。

### 根因

步驟 4 的前方裁切使用 `Part.makeBox(200, 200, 200, V(-100, -100, 140))` 在 Z=140 處進行**平面切割**。對球形殼體做平面截切，必然在截面上暴露出球殼的**環狀橫截面**（外半徑 R=17、內半徑 R=15 之間的環形），形成可見的平板面（面積 ≈ 106.7mm²）。

**核心認知**：任何平面切割球形殼體，都會在切面上暴露環狀橫截面。這是幾何必然，無論平面位置如何移動都無法消除。

### 修正方案（球體削切法）

用**球面**替代平面進行前方裁切，使球殼壁厚在前方邊緣**漸變為零**，而非被平面截斷：

| 步驟 | 舊做法 | 新做法 |
|------|--------|--------|
| 前方粗裁 | `makeBox(..., V(-100,-100,140))` | `makeBox(..., V(-100,-100,141))` — Z=141，保留 1mm 緩衝 |
| 前方精修 | （無） | `makeSphere(17.6, V(0, R_out, 145.5))` — 球面削切，曲面漸變 |

球體削切的原理：裁切球（R=17.6）略大於球殼外球（R=17），且中心偏前方（Z=145.5 vs 球殼中心 Z=140）。兩球面交線形成**弧形邊界**，在交線處球殼壁厚連續遞減至零，不產生任何平坦截面。

### 執行內容

以完整重建腳本為基礎，僅修改步驟 4 的前方裁切部分：

```python
# 舊：單一平面裁切（產生平板面）
# trim_front = Part.makeBox(200, 200, 200, V(-100, -100, 140))
# dome = dome.cut(trim_front)

# 新：兩段式裁切（消除平板面）
# 粗裁：Z=141 平面移除大部分前方球殼
trim_front_box = Part.makeBox(200, 200, 200, V(-100, -100, 141))
dome = dome.cut(trim_front_box)
# 精修：球面削切，壁厚漸變為零

```

## 2026-04-10　修復水平馬達臂穿線孔阻塞

### 背景

使用者發現水平馬達臂的穿線孔（D=6mm）被堵住——線材無法從外壁穿入馬達腔。此問題源自上一次「外殼延長 + 馬達臂加寬」操作。

### 根因

馬達臂加寬時 cx 從 62→67，導致馬達孔（D=32）內壁從 X=46 移至 **X=51**。但穿線孔起始位置仍為 `V(R_out+5, 0, 169)` = `V(50, 0, 169)`，使穿線孔終點 X=50−20=30 雖深入臂內，起始端卻與馬達腔之間殘留 **1mm 實體壁**（X=50~51），完全堵塞通道。

### 修正方案

| 參數 | 舊值 | 新值 | 說明 |
|------|------|------|------|
| 穿線孔起始 X | R_out+5 = 50 | **R_out+10 = 55** | 從外壁更外側開始 |
| 穿線孔長度 | 20mm | **25mm** | 確保貫穿至馬達腔 |
| 與馬達腔重疊 | ~4mm（原設計） | **4mm** | 維持原設計重疊量 |

### 執行內容

# 左側穿線孔修復（鏡像）
