# Bambu Studio 防水切片參數設定

> **適用模型**：ROV 潛水艇 PETG 外殼 v5.1（repo 根目錄 `ROV_Hull.stl` / `ROV_EndCaps.stl` / `ROV_Fasteners.stl`）
> **印表機**：Bambu Lab A1
> **耗材**：PETG HF 灰色
> **目標**：層間完全融合、消除微縫、達到防水要求
> **最後更新**：2026-07-20（v5.1：新增分件總覽、螺絲專用參數、殼體空心腔注意事項）

## 分件列印總覽（v5.1）

| 檔案 | 擺向 | 支撐 | 層高 | 特別注意 |
|------|------|------|------|----------|
| `ROV_Hull.stl` | **直立，後端（Z=0 法蘭）朝下** | ✅ tree(auto)：馬達臂、前法蘭、煙囪、觀察窗墊座 | 0.16 mm | 下方「防水參數」全套；Brim 8mm |
| `ROV_EndCaps.stl` | 圓盤平面朝下（兩件同盤） | ❌ 免支撐 | 0.16 mm | 同套防水參數（100% 填充） |
| `ROV_Fasteners.stl` | **螺絲直立（頭朝下）、螺帽平放** | ❌ 免支撐 | **0.12 mm** | 見「列印螺絲/螺帽專用參數」 |

| Layer height | **0.16 mm** | 層高越薄，層間接觸面積越大，融合更好，防水性顯著提升 |
| Initial layer height | 0.20 mm | 維持不變，第一層稍厚有助附著 |

| Smart scarf seam | ✅ 開啟 | Scarf seam 避免 Z seam 處留縫，對防水很重要 |
| X-Y hole compensation | 0 mm | 維持，視實測再調 |

## Strength（強度）⚡ 改動最多

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **Wall loops** | **4** | **最關鍵！** 1.5mm ÷ 0.45mm ≈ 3.3 條，設 4 讓壁圈緊密重疊壓實，消除壁間空隙 |
| **Detect thin wall** | **✅ 開啟** | **必開！** 壁厚 1.5mm 屬薄壁，不開此項會出現未填充的窄縫 |
| Top shell layers | **7** | 頂面多幾層實心，封頂更密實（配合 0.16mm 層高） |
| Bottom shell layers | **5** | 底面加厚 |
| Top shell thickness | **1.12 mm** | 7 × 0.16 mm |
| **Sparse infill density** | **100%** | **防水件必須 100% 填充！** 15% 的 Grid 會留大量空腔，水壓下必然滲漏 |
| Sparse infill pattern | Concentric | 100% 填充時 Concentric 對圓柱體密封性最佳 |
| Infill/Wall overlap | **25%** | 壁圈與填充多重疊，消除接合線微縫（原 15%） |
| Ensure vertical shell thickness | Enabled ✅ | 維持 |
| Detect floating vertical shells | ✅ | 維持 |

## 耗材 / 印表機設定（Filament & Printer）

> 以下設定在 Bambu Studio 的耗材設定或印表機設定分頁調整，**這些對防水影響極大**。

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **噴嘴溫度** | **240 ~ 245°C** | PETG 高溫印能顯著改善層間融合，是防水最重要的非切片參數 |
| 熱床溫度 | **80°C** | PETG 標準 |
| **冷卻風扇** | **30 ~ 50%**（前幾層 0%） | 風扇越低層間溫度越高融合越好；太低會拉絲，30-50% 為平衡點 |
| Max volumetric speed | ≥ **12 mm³/s** | 100% 填充 + 0.45mm 線寬需足夠擠出量，確保不欠料 |

## 列印螺絲/螺帽專用參數（ROV_Fasteners.stl，v5.1 真螺紋）

> 螺紋規格：芯 D3.0、牙頂 D4.4、螺距 2.0、**牙深 0.7mm（接近 FDM 可印極限）**。
> 這一盤與防水無關，目標是把螺紋印出來且不斷桿；**不要沿用殼體的防水參數檔**。

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **Layer height** | **0.12 mm** | 螺距 2.0 ÷ 0.12 ≈ 17 層/圈，牙型才完整；最粗不超過 0.16 |
| 擺向 | 螺絲**直立、頭朝下**；螺帽平放 | STL 內建此方位，直接切片即可 |
| Wall loops | 3 | 桿徑小，實際近全壁；牙尖由外壁成形 |
| Sparse infill | 100% | 小件用料少，實心強度最好 |
| **Outer wall 速度** | **40~60 mm/s** | 細桿慢印，牙型清晰、層間黏合好 |
| 冷卻風扇 | **50~80%** | 小截面散熱不及會糊牙（與殼體低風扇相反）|
| 噴嘴溫度 | 240°C | 同耗材設定即可 |
| Brim | **每件 3~5 mm** | 螺絲高 23.5mm、桿細，無 brim 易被撞倒 |
| Seam | Aligned 或 Rear | 讓 Z seam 固定一側，避免散佈在牙面 |
| X-Y hole compensation | 0 | 螺帽間隙已建在模型（+0.25 徑向），先照印再實測 |
| 支撐 | ❌ 關閉 | 螺紋 45° 內自撐 |

**首印驗收**：① 螺絲徒手旋入螺帽全程可轉（過緊→反覆旋合磨合，勿硬扳）；
② 螺絲穿過法蘭 D4.8 孔（孔實印約 4.2~4.4，牙頂 4.4 屬緊滑配，必要時通孔）；
③ 僅手緊使用，斷裂/滑牙改金屬 M4×20+螺帽（孔位相容）。

## 防水效果優先順序

改動效益從大到小排序：

1. 🥇 **Wall loops 2→4 + Detect thin wall 開啟** — 消除 1.5mm 壁內空隙
2. 🥈 **Infill 15%→100%** — 消除內部空腔
3. 🥉 **噴嘴溫度 240-245°C + 風扇降到 30-50%** — 提升層間黏合力
4. **Layer height 0.2→0.16mm** — 增加層間密封面積
5. **外壁速度 200→80 mm/s** — 讓塑料充分融合
6. **Infill/Wall overlap 15%→25%** — 消除壁-填充接縫

## 印完後驗證

1. **目視檢查**：外壁應無可見縫隙或透光點
2. **浸水測試**：密封兩端後完全浸入水中，觀察是否冒泡
3. **加壓測試**（選用）：用注射器從穿線孔注水加壓至 0.1 bar，保壓 5 分鐘無滲漏
4. **配合檢查**（v5.1，對照需求文件 §12 量測清單）：
   - 螺栓孔實印孔徑 ≥ 4.0mm（金屬 M4 通過；列印螺絲牙頂 4.4 通過）
   - 馬達孔 D30 為緊配，過緊以砂紙修內壁
   - 端蓋定位環伸入艙口順暢、可壓到墊圈凹槽內的墊圈（墊圈厚 2.5~3mm）
   - 電池 75×56×66 入電池艙、配重塊 65.6×42.2 入配重凹槽
   - 列印螺絲×螺帽旋合手感（見螺絲專用參數的首印驗收）
