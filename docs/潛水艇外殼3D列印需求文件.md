## 一、整體尺寸與座標系定義

### 1.1 設計目標尺寸

| 項目 | 數值 | 說明 |
|------|------|------|
| 外徑（OD） | **120 mm** | v4.0：內徑 +30mm 後之外徑 |
| 壁厚 | **1.5 mm** | PETG FDM 薄壁（約 3 層壁圈，0.4mm 噴嘴）|
| 內徑（ID） | **117 mm** | OD − 2 × 壁厚（v4.0：87 → 117）|
| 總長 | **250 mm** | 一體成型，在 Bambu A1 256 mm 限制內（僅餘 6mm）|
| 端面法蘭（每端） | **OD=144、厚 6 mm** | v4.0：取代 PP 插槽，8× D4.8 螺栓孔 |
| 主艙有效長度 | **≈ 230 mm**（全徑段） | 兩端環形棚架之間 Z=10~240；棚架內徑 D=102 |
| 主圓筒排水體積 | **≈ 2830 cm³** | π × 6² × 25 cm（浮力計算基準，不含法蘭/外突特徵）|

> **⚗️ 浮力說明（v5.0 重算）**：排水合計約 3100 g（淡水）。列印件實測體積：殼體 552 cm³ ≈ **701 g**（含實心平臺 ≈320g，兼底部配重）、端蓋 2×88 cm³ ≈ 223 g、螺絲螺帽 ≈ 12 g。估算總重 ~2400 g（列印件 ≈936g + 馬達 450g + 電池 600g + 電子 200g + 其他 200g）。淨浮力 **≈ +700 g（正浮力）**，**仍須加裝艙內配重（鉛塊/鋼板置於平臺上或電池艙旁）**才能下潛；實心平臺已將配重需求從 v4.0 的 ≈1000g 降低並固定於艇底（重心低、穩定性佳）。

> **電池放置驗證（v5.0）**：電池 75×56×66mm 放入專用電池艙（艙底 Y=−45、X±29、Z=12~89），頂部至艙頂淨空 >35mm ✓（數值探針驗證通過）。

### 1.2 一體成型設計說明

本版外殼為**一體成型，不拆分段落**。250 mm 總長在 Bambu Lab A1（最大 256 mm）範圍之內（僅餘 6mm），可單次完成 FDM 列印，無需後續接縫補強。

> **1.5mm 壁厚列印注意**：壁厚僅 1.5mm，以 0.4mm 噴嘴恰好 3~4 絲。建議 Bambu Studio 將外牆圈數設為「自動配合壁厚」，不開填充，全靠壁圈保持強度。外部特徵（馬達座根部）接合處應力集中，建模時加用 3mm 壁圍包覆。

### 1.3 PP 端蓋來源說明 —— ❌ v4.0 已廢除

> **v4.0（2026-07-19）起改用螺栓法蘭端蓋（見 §2）**。
> PP 保鮮盒端蓋（OD ≈ 90mm）與新殼體（OD = 120mm）不相容，全面停用；
> 原 PP 插槽特徵已自模型移除。

### 1.4 FreeCAD 座標系

- **Z 軸**：艇體長軸方向（正方向 = 艇首方向）
- **X 軸**：艇體水平橫向（正方向 = 右舷）
- **Y 軸**：艇體垂直方向（正方向 = 艇頂）
- **原點**：艇體後端面中心

```
後端 (Z=0)   ←────── 250 mm ──────→   前端 (Z=250)
   ┌─┬──────────────────────────────────┬─┐
   │法│         主艙有效艙室             │法│
   │蘭│    （有效長 ≈240 mm）           │蘭│
   └─┴──────────────────────────────────┴─┘
   Z=0~6                              Z=244~250
        OD = 120 mm，壁厚 1.5 mm，法蘭 OD = 144 mm
```

## 二、FreeCAD 建模流程（逐步指令）

> **⚠️ FreeCAD MCP 建模方式**：FreeCAD MCP 透過 `execute_code` 執行 Python 腳本，**無法使用互動式 PartDesign 工作流程**（Sketch → Pad → Pocket）。以下各步驟的描述僅作為**設計意圖說明**；實際建模時須改用 **Part 模組 CSG 布林法**（`Part.makeCylinder`、`Part.makeBox`、`Shape.cut()`、`Shape.fuse()` 等）。完整 Python 腳本範本見第十三節。

### 步驟 1：建立主體圓筒

```
操作：CSG 布林法 — 外圓柱 cut 內圓柱

  外圓柱：R = 60 mm（OD = 120 mm），高 250 mm
  內圓柱：R = 58.5 mm（ID = 117 mm），高 250 mm
  hull = outer.cut(inner)
  → 得到：外徑 120 mm、壁厚 1.5 mm、長 250 mm 的中空圓筒
```

### 步驟 2/3：端面螺栓法蘭 ×2（v4.0，取代 PP 插槽）

兩端各一圈環形法蘭，與殼體一體成型，供螺栓端蓋鎖固：

| 參數 | 數值 |
|------|------|
| 法蘭外徑 | **144 mm**（R=72）|
| 法蘭厚度（軸向） | **6 mm**（後端 Z=0~6、前端 Z=244~250）|
| 螺栓孔 | **8× D=4.8 mm**（M4 過孔，含列印縮孔補償 ≈0.5mm）|
| 螺栓分佈圓（BCD） | **132 mm**（r=66），45° 等分、起始角 22.5°（22.5°、67.5°…337.5°，避開尾翼平面）|
| 緊固件 | 列印螺絲+螺帽（§2.3）或市售 M4×20 + 螺帽（金屬件更可靠）|
| 密封 | **v5.0：墊圈改放艙內墊圈凹槽（§2.2）**，由端蓋定位環壓緊；不再夾在法蘭面，墊圈不需開螺栓孔 |

```
CSG 操作（每端）：
  1. fuse 全圓柱 R=72、H=6（後端 Z=0；前端 Z=244）
  2. cut R_in 內圓柱（恢復艙內通孔）
  3. cut 8× D=4.8 螺栓孔（沿 Z 軸貫穿法蘭，r=66 圓上 45° 等分、起始角 22.5°）
螺帽鎖在法蘭背面（後端法蘭背面 Z=6、前端 Z=244），
最近特徵為尾翼 Z=19 / 馬達臂 Z=194，扳手淨空足夠。
```

### 2.1 螺栓端蓋（v5.0：前/後兩個獨立設計，合併匯出 `ROV_EndCaps.stl`）

| 參數 | 後蓋 `ROV_EndCap_Rear` | 前蓋 `ROV_EndCap_Front` |
|------|------|------|
| 外形 | 圓盤 R=72、厚 **5 mm** | 同左 |
| 定位凸緣（環） | R=54.2~58.2、高 **5 mm**（伸入艙孔，末端伸入墊圈凹槽 1mm 壓緊墊圈）| 同左 |
| 螺栓孔 | 8× D=4.8，BCD=132（與法蘭對齊）| 同左 |
| 穿線孔 | — 無 | **D=6（R3），偏心 20mm**（燈板線路穿入艙內，穿線後環氧灌封）|
| 列印方式 | 平面朝下、環朝上，免支撐 | 同左 |

> **前蓋穿線孔用途**：艇首外部擺放長方形燈板，燈板上方另罩透明罩密封；
> 燈板線路經此偏心小孔進入艙內。孔偏離中心 20mm（避開燈板中心結構），
> 8 螺栓孔為 45° 對稱，組裝時可任選方位對準燈板走線位置。

### 2.2 墊圈凹槽 + 環形棚架（v5.0 新增，艙內兩端）

端蓋的定位環伸入艙內凹槽、壓住放在槽內的橡膠墊圈——「舌槽式軸向端面密封」。

| 參數 | 數值 |
|------|------|
| 環形棚架 | R=51~58.6、軸向 6mm（後端 Z=4~10、前端 Z=240~246），與殼內壁一體成型 |
| 墊圈凹槽 | R=53.7~58.6、深 **3 mm**（後端槽底 Z=7、前端槽底 Z=243，開口朝端面）|
| 端蓋環末端 | 全鎖緊時伸入凹槽 **1 mm**（後端環尖 Z=5 / 前端 Z=245）|
| 墊圈壓縮空間 | 環尖到槽底 **2 mm** → **壓縮量 = 墊圈厚 − 2mm** |
| 建議墊圈 | 自裁橡膠圈 OD≈117 / ID≈108、總厚 **2.5~3 mm**（自行車內胎 ≈1.2mm 可疊 2~3 層）|
| 配合間隙 | 環 R54.2~58.2 vs 凹槽 R53.7~58.6：內側 0.5 / 外側 0.4（探針驗證 0 干涉）|

> 硬停點是「端蓋圓盤貼緊法蘭面」，此時墊圈空間固定為 2mm——墊圈太薄會壓不到（漏水）、
> 過厚則蓋不平，首次組裝時以疊層數微調。

### 2.3 列印螺絲 ×16 + 螺帽 ×16（v5.0 新增，`ROV_Fasteners.stl`）

| 參數 | 數值 |
|------|------|
| 螺絲 | 六角頭對邊 8×厚 3.5；桿長 20（頭下）；**粗牙**：芯 **D3.0**、牙頂 D4.4、螺距 2.0、牙深 **0.7**（v5.1）|
| 螺帽 | 六角對邊 9×厚 4；內牙刀具芯 r1.75 同牙深（與螺絲 +0.25mm 徑向間隙，探針驗證旋合 0 干涉）|
| ⚠ 建模工法 | 螺紋（helix+makePipeShell）與芯柱**必須用 fuzzy fuse：`core.fuse(thread, 0.05)`**。普通 `fuse` 會回傳 Solids=2（OCC 未合併），後續 `common` 會把螺紋悄悄丟掉（v5.0 踩坑：螺絲印不出螺紋）。fuse 後驗證 Solids==1 且體積 > 純圓柱值 |
| 相容性 | 牙頂 D4.4 可通過法蘭/端蓋 D4.8 孔（含縮孔補償後仍有餘裕）|
| 列印 | 螺絲直立（頭朝下）、螺帽平放；建議 0.12~0.16mm 層高、慢速 |
| ⚠ 強度注意 | 塑膠螺絲芯徑僅 3.3mm，**只能手感鎖緊、不可用力扳緊**；若斷裂或滑牙，改用金屬 M4×20+螺帽（孔位完全相容）|

> **浮力不足警示**：重新計算後艇體浮力約 **−0 g**（艇體排水 ≈ 總重）。

|------|------|

## 十三、FreeCAD MCP 建模指令摘要（CSG 布林法）

> **📌 腳本定位：災難重建用**
>
> 此腳本的用途是**當 FCStd 檔案損毀或遺失時，可從零完全重建模型**。
> 日常建模**禁止**直接執行此腳本（應在既有模型上局部修改）。
> 腳本中標記 `⬜ 未實作` 的步驟表示規格已定義但尚未建模，待日後補上時一併更新腳本。

> **🔴 執行方式（critical）**：
>
> **選項 A — 單次執行（推薦）**：將整段腳本作為**一次** `execute_code` 呼叫送出。
> 所有步驟共用同一個 `hull` 變數，一次完成所有 CSG 布林操作後再寫入文件。
>
> **選項 B — 逐步執行**：若需逐步驗證，每完成一步必須將 `hull` 存回文件物件：
> ```python
> # 每步結尾固定加這三行
> obj = doc.getObject("ROV_Hull") or doc.addObject("Part::Feature", "ROV_Hull")
> obj.Shape = hull
> doc.recompute()
> ```
> 下一步開頭固定加：
> ```python
> obj = doc.getObject("ROV_Hull")
> hull = obj.Shape
> ```
>
> **⚠️ 不做上述持久化，步驟間的 `hull` 變數會消失，導致模型只剩最後一步的零件碎片！**
>
> **迭代建模規定**：
> - **必須開啟上一個版本的 `.FCStd` 檔案**作為基底。
> - **嚴禁 `FreeCAD.newDocument()` 從頭建立新文件**（除非是全新第一版）。
> - 每個重要步驟完成後用 `get_screenshot` 截圖確認。

OD, WALL, L = 120.0, 1.5, 250.0        # 外徑 / 壁厚 / 總長（ID = 117）

VM_HOUS_R, VM_POCK_R = 18.0, 15.0      # 外殼 R18（OD36）；孔 R15（D30 緊配馬達）

    return Part.makeCylinder(R_in, L + 4, V(0, 0, -2))   # 艙內修整刀

        raise RuntimeError("GEOMETRY BAD at " + tag)

    holes.append(Part.makeCylinder(BOLT_R, FLANGE_T + 2, V(x, y, -1)))
    holes.append(Part.makeCylinder(BOLT_R, FLANGE_T + 2, V(x, y, L - FLANGE_T - 1)))

hull = hull.fuse(Part.makeCylinder(PAD_R, PAD_TOP, V(0, 0, OBS_Z), V(0, 1, 0)))

hull = hull.fuse(dome)
hull = hull.cut(Part.makeCylinder(OBS_HOLE_R, 7.0, V(0, R_in - 2, OBS_Z), V(0, 1, 0)))
chk("obs window", hull)

hull = hull.cut(bore())

y0 = R_in - 2.5
hull = hull.cut(Part.makeCone(CONE_R_IN - slope * 2.5, CONE_R_OUT + slope * 1.0,
                              CH_TOP + 1.0 - y0, V(0, y0, CH_Z), V(0, 1, 0)))
hull = hull.cut(Part.makeCylinder(CONE_R_IN, 4.0, V(0, 56.0, CH_Z), V(0, 1, 0)))
chk("chimney", hull)

armR = Part.makeBox(ARM_XL + 10.0, ARM_YL, ARM_ZL, V(R_out - 10.0, -ARM_YL / 2, ARM_Z0))

       V(R_out + FIN_SPAN, 0, FIN_Z0), V(R_out - 2, 0, FIN_Z0)]

chk("platform", hull)

# ── 步驟 13：平臺空心腔 ×2（v5.1；封閉腔、+Z 端 45° 收斜頂免支撐）──
def cavity(z0, z1):
    pts = [V(-CAV_XW, CAV_Y0, z0), V(-CAV_XW, CAV_Y0, z1 - 7.0),
           V(-CAV_XW, CAV_Y1, z1), V(-CAV_XW, CAV_Y1, z0), V(-CAV_XW, CAV_Y0, z0)]

# ── 步驟 13：端蓋 ×2（前蓋含偏心穿線孔 R3 @ 偏心 20mm）────────
def make_cap(wire_hole):
    cap = Part.makeCylinder(FLANGE_R, CAP_T)
    ring = Part.makeCylinder(SPIG_O, SPIG_H, V(0, 0, CAP_T)).cut(
           Part.makeCylinder(SPIG_O - SPIG_W, SPIG_H + 1, V(0, 0, CAP_T)))
    cap = cap.fuse(ring)
    cutters = []
    for k in range(BOLT_N):
        a = math.radians(BOLT_A0 + 45.0 * k)
        cutters.append(Part.makeCylinder(BOLT_R, CAP_T + 2,
                       V(BCD_R * math.cos(a), BCD_R * math.sin(a), -1)))
    if wire_hole:
        cutters.append(Part.makeCylinder(CAPF_WIRE_R, CAP_T + 2, V(0, CAPF_WIRE_OFF, -1)))
    cap = cap.cut(cutters[0].multiFuse(cutters[1:]))
    try:
        cap = cap.removeSplitter()
    except Exception:
        pass
    if not cap.isValid() or len(cap.Solids) != 1:
        raise RuntimeError("cap bad")
    return cap

# ── 步驟 14：列印螺絲 ×16 + 螺帽 ×16（粗牙 pitch=2、牙頂 D4.4，v5.1 真螺紋）─
# ⚠ 螺紋與芯柱必須 fuzzy fuse(0.05)：普通 fuse 回傳 Solids=2、後續 common 會丟失螺紋
def threaded_rod(r_core, depth, pitch, length):
    helix = Part.Wire(Part.makeHelix(pitch, length, r_core))
    a = 0.62 * pitch / 2.0
    tri = Part.Wire(Part.makePolygon([
        V(r_core - 0.2, 0, -a), V(r_core - 0.2, 0, a),
        V(r_core + depth, 0, 0), V(r_core - 0.2, 0, -a)]))
    thread = helix.makePipeShell([tri], True, True)
    rod = Part.makeCylinder(r_core, length).fuse(thread, 0.05)   # fuzzy fuse
    if len(rod.Solids) != 1 or rod.Volume < math.pi * r_core**2 * length + 10.0:
        raise RuntimeError("thread lost in fuse")
    return rod.common(Part.makeCylinder(r_core + depth + 1.0, length))

def hexprism(circR, t):
    pts = [V(circR * math.cos(math.radians(60 * i)),
             circR * math.sin(math.radians(60 * i)), 0) for i in range(6)]
    pts.append(pts[0])
    return Part.Face(Part.makePolygon(pts)).extrude(V(0, 0, t))

hexR9 = 4.5 / math.cos(math.radians(30))   # 螺帽   對邊 9

nut_tool.translate(V(0, 0, -1.25))
nut = hexprism(hexR9, 4.0).cut(nut_tool)
items = []
for i in range(16):
    s = screw.copy(); s.translate(V(14.0 * (i % 4), 14.0 * (i // 4), 0)); items.append(s)
for i in range(16):
    n = nut.copy(); n.translate(V(70.0 + 13.0 * (i % 4), 13.0 * (i // 4), 0)); items.append(n)
fasteners = Part.makeCompound(items)

> **⚠️ 使用注意**：
> 1. 上述腳本為**參考範本**，座標計算可能需要依實際量測值微調。
> 2. **推薦單次執行**（選項 A），避免步驟間變數消失導致模型碎裂。
> 3. **`makeFillet`/`makeChamfer` 只能用在「尚未布林的乾淨原始體」**（如步驟 5 的獨立 box）——對布林後的複雜體操作易導致幾何崩潰；曲面接合處倒角改為列印後砂磨。
> 4. **禁止使用 `Part.makeTorus`** 做收邊凹槽——改用環形圓柱 cut，幾何更穩定。
> 5. **貼合外壁技巧**：任何外突結構（煙囪、馬達外殼）均採「先 fuse 過大尺寸，再 cut 內圓柱」方式讓底面自動貼合外壁圓弧。
