# ROV Hull 3D 列印模型

這個倉庫包含一個 FreeCAD 原始設計檔，以及一個可直接列印的 STL 模型檔。簡單來說，FreeCAD 檔是用來修改設計，STL 檔是用來切片與列印。

## 檔案說明

- [ROV_Hull.FCStd](ROV_Hull.FCStd)：FreeCAD 原始檔，保留完整建模資料與參數。若要調整外型、尺寸、孔位、支架或重新匯出模型，請開啟這個檔案。
- [ROV_Hull.stl](ROV_Hull.stl)：3D 列印用的 STL 網格檔，可直接匯入 Bambu Studio、Cura 等切片軟體。

## 使用流程

1. 如果要改模型，先用 FreeCAD 開啟 [ROV_Hull.FCStd](ROV_Hull.FCStd)。
2. 調整完成後，重新匯出 STL。
3. 如果只是要印件，直接使用 [ROV_Hull.stl](ROV_Hull.stl) 即可。

## 模型摘要

### 整體尺寸

| 項目 | 數值 | 說明 |
|------|------|------|
| 外徑（OD） | **90 mm** | 對齊 PP 端蓋外徑 |
| 壁厚 | **1.5 mm** | 約 3 層壁圈（0.4mm 噴嘴） |
| 內徑（ID） | **87 mm** | OD − 2 × 壁厚 |
| 總長 | **250 mm** | 一體成型，控制在 Bambu A1 256mm 限制內 |
| PP 端蓋插入槽深（每端） | **10 mm** | 前後各一，插入後外表面齊平 |
| 主艙有效長度 | **230 mm** | 250 − 10 × 2 |

### 座標系

- **Z 軸**：艇體長軸（Z=0 後端 / Z=250 前端）
- **Y 軸**：垂直方向（Y+ 為艇頂）
- **X 軸**：水平橫向（X+ 為右舷）
- **原點**：艇體後端面中心

```
後端(Z=0)  ←────────── 250 mm ──────────→  前端(Z=250)
	┌──────────────────────────────────────────┐
	│←10mm→      主艙有效艙室      ←10mm→ │
	│PP 插槽  （有效長 230 mm）  PP 插槽   │
	└──────────────────────────────────────────┘
				  OD = 90 mm，壁厚 1.5 mm
```

## 列印參考設定

### Quality（品質）

| 參數 | 建議值 | 說明 |
|------|--------|------|
| Layer height | **0.16 mm** | 層高越薄，層間融合越好，防水性提升 |
| Initial layer height | 0.20 mm | 第一層稍厚有助附著 |
| Outer wall 線寬 | **0.45 mm** | 略加寬填滿層間微縫 |
| Inner wall 線寬 | **0.46 mm** | 同理 |
| Smart scarf seam | ✅ 開啟 | 避免 Z seam 留縫，對防水關鍵 |

### Strength（強度）

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **Wall loops** | **4** | 1.5mm ÷ 0.45mm ≈ 3.3，設 4 讓壁圈緊密壓實 |
| **Detect thin wall** | **✅ 開啟** | 壁厚 1.5mm 屬薄壁，不開會出現未填充縫隙 |
| Top shell layers | **7** | 頂面密實（配合 0.16mm 層高） |
| Bottom shell layers | **5** | 底面加厚 |
| **Sparse infill density** | **100%** | 防水件必須 100% 填充 |
| Sparse infill pattern | Concentric | 100% 填充時對圓柱體密封性最佳 |
| Infill/Wall overlap | **25%** | 消除壁-填充接縫微縫 |

### Speed（速度）

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **Outer wall** | **80 mm/s** | 慢速讓塑料充分融合 |
| **Inner wall** | **120 mm/s** | 同理降速 |
| Small perimeters | **≈ 32 mm/s** (40%) | 細節處密合 |
| Top surface | **100 mm/s** | 確保封頂密實 |
| Sparse infill | **150 mm/s** | 100% 填充不宜太快 |
| Initial layer | **30 mm/s** | 確保牢牢附著 |

### Support（支撐）

| 參數 | 建議值 |
|------|--------|
| Enable support | ✅ |
| Type | Tree (auto) |
| Top / Bottom Z distance | **0.16 mm**（= 1 層高） |
| Threshold angle | 30° |

### Others（其他）

| 參數 | 建議值 |
|------|--------|
| Brim type | Auto |
| Brim width | **8 mm**（200mm 高圓柱易翹曲） |
| Spiral vase | ☐ 關閉 |

### 耗材與印表機設定

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **噴嘴溫度** | **240 ~ 245°C** | 高溫顯著改善層間融合，防水最重要的參數 |
| 熱床溫度 | **80°C** | PETG 標準 |
| **冷卻風扇** | **30 ~ 50%** | 太高會降低層間黏合力 |
| Max volumetric speed | ≥ **12 mm³/s** | 100% 填充需足夠擠出量 |

## 防水效果優先順序

1. **Wall loops 2→4 + Detect thin wall 開啟** — 消除 1.5mm 壁內空隙（最關鍵）
2. **Infill 15%→100%** — 消除內部空腔
3. **噴嘴溫度 240–245°C + 風扇降至 30–50%** — 提升層間黏合力
4. **Layer height 0.2→0.16mm** — 增加層間密封面積
5. **外壁速度 200→80 mm/s** — 讓塑料充分融合
6. **Infill/Wall overlap 15%→25%** — 消除壁-填充接縫
